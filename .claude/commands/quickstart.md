# Quick Start 快速启动

快速开始新项目或新功能开发，自动按最佳实践流程引导。

## 执行流程

### 1. 需求理解（product-manager）
- 理解用户需求
- 明确项目目标和范围
- 识别核心功能和优先级

### 2. 技术架构（developer）
- 技术栈选型
- 系统架构设计
- 数据模型规划

### 3. API 设计（api-designer，如需要）
- 设计 RESTful/GraphQL API
- 定义接口规范
- 编写 API 文档

### 4. UI/UX 设计（designer，如需要）
- 设计用户界面
- 创建设计系统
- 输出组件规范

### 5. 开发执行（developer）
- 实现代码
- 确保代码质量

### 6. 测试验证（test-engineer）
- 编写单元测试
- 编写集成测试
- 确保覆盖率 > 80%

### 7. 代码审查（code-reviewer）
- 审查代码质量
- 检查安全漏洞
- 评估性能

### 8. 部署准备（devops-engineer，如需要）
- 配置 CI/CD
- 准备部署脚本
- 设置监控告警

## 相关命令
- deploy - 快速部署
- review - 代码审查
- optimize - 性能优化
