# UI/UX 设计工作流

## 设计原则
- 用户优先：以用户需求为中心
- 简洁明了：避免复杂和冗余
- 一致性：保持设计系统一致
- 可访问性：符合 WCAG 标准

## 常用设计模式

### 导航模式
- **顶部导航** - 适合少量主要功能
- **侧边导航** - 适合多层级内容
- **底部导航** - 适合移动端主要功能
- **汉堡菜单** - 适合次要功能

### 表单设计
- **单列布局** - 提高完成率
- **内联验证** - 即时反馈
- **清晰标签** - 减少困惑
- **进度指示** - 多步骤表单

### 数据展示
- **卡片** - 适合异构内容
- **列表** - 适合同类内容
- **表格** - 适合结构化数据
- **图表** - 适合数据可视化

## 输出格式

### 设计交付物

```markdown
## UI/UX 设计交付

### 设计文件
- Figma 设计文件链接
- 导出的 PNG/SVG 资源
- 图标和插图资源

### 设计规范
- 颜色系统（主色、辅助色、语义色）
- 字体系统（字号、行高、字重）
- 间距系统（4px/8px 基准）
- 组件库（按钮、输入框、卡片等）

### 交互说明
- 用户流程图
- 交互原型链接
- 状态变化说明
- 动画效果说明

### 响应式设计
- 移动端设计（375px）
- 平板端设计（768px）
- 桌面端设计（1440px）
```
