- 100% 按照 PLAN 阶段文档执行

## 阶段 6: 提交代码

### Git 操作
- [ ] 检查变更文件（git status）
- [ ] 暂存文件（git add）
- [ ] 编写提交信息（Conventional Commits）
- [ ] 提交代码（git commit）

### 提交信息格式
`
<type>(<scope>): <subject>

<body>

<footer>
`

**类型**: eat、ix、efactor、	est、docs、style、perf、chore

**示例**:
`
feat(auth): add JWT authentication

- Implement JWT token generation
- Add authentication middleware
- Add login/logout endpoints

Closes #123
`

## 常见问题处理

### 发现规划问题
1. 立即暂停开发
2. 向用户说明问题
3. 提供建议方案
4. 等待用户确认后继续

### 技术难题
1. 搜索现有代码库中的类似实现
2. 查阅技术文档
3. 向用户说明困难和可能的解决方案
4. 获得用户确认后实施

### 测试失败
1. 分析失败原因
2. 修复代码或测试
3. 重新运行测试
4. 确保所有测试通过
